# Google Play launch checklist

- Create a Google Play Console developer account.
- Choose a unique package ID (the project default is `com.seratime.app`).
- Add a real app icon and feature graphic.
- Prepare phone screenshots.
- Host a real privacy policy URL.
- Complete Data safety declarations accurately, including account information, profile photos/selfies, user-generated content, uploaded files and financial information.
- Complete the content rating questionnaire.
- Declare advertising/monetization where required. The current app includes a 320x50 third-party banner.
- Create a signed Android App Bundle (`.aab`) in Android Studio.
- Upload first to an internal/closed testing track.
- Test login/signup, worker onboarding, task application, 10-applicant selection, rejection notifications, submission, secure preview, accept, 2-complaint limit, wallet and logout.
- Fix all crash/ANR reports before production.
